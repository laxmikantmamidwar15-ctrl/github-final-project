# Simple Interest Calculator

## Project Description
A Bash-based calculator that computes simple interest using the principal amount, annual interest rate, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Inputs
- Principal amount
- Annual rate of interest
- Time period in years

## Technology Used
- Bash scripting
- Linux command line

## How to Run
Run the script using:

bash simple-interest.sh

## Example
Principal: 1000
Rate: 5%
Time: 2 years

Simple Interest: 100
Total Amount: 1100
